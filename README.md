# 🌍 REST Countries Explorer Web Application

A modern and responsive web application built using **Python**, **Django**, **HTML**, **CSS**, and **JavaScript** that allows users to explore detailed information about countries around the world using the REST Countries API.

---

## 🚀 Features

- 🌎 View all countries dynamically
- 🔍 Search countries by name
- 🌐 Filter countries by region
- 🏳️ Display:
  - Country Flag
  - Capital
  - Population
  - Region
  - Subregion
  - Languages
  - Currencies
  - Timezones
  - Maps Location
  - Coat of Arms
  - Car Side & Signs
- 📱 Fully responsive design
- 🗺️ Google Maps embedded location support
- ⚡ Fast and user-friendly interface

---

## 🛠️ Technologies Used

- **Python**
- **Django**
- **HTML5**
- **CSS3**
- **JavaScript**
- **Bootstrap**
- **REST Countries API**
